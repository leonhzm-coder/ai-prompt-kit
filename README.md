# AI Agent 实战提示词工具包

30 个经过实战检验的 AI 提示词，覆盖写作、办公、数据、营销、成长五大场景。复制粘贴就能用，让 AI 从聊天工具变成真能干活的数字员工。

👉 [在线产品页面](https://leonhzm-coder.github.io/ai-prompt-kit)

## 内容

- 写作创作类（7 个）：公众号爆文、小红书种草、抖音脚本、商务邮件、文章润色、品牌故事、产品文案
- 办公效率类（8 个）：会议纪要、周报月报、PPT 大纲、项目管理、文档校对、合同审阅、面试准备、工作复盘
- 数据分析类（5 个）：数据解读、Excel 公式、图表建议、市场调研、竞品分析
- 营销增长类（5 个）：社群运营、朋友圈营销、SEO 策略、广告文案、用户画像
- 个人成长类（5 个）：知识管理、读书笔记、学习规划、职场沟通、时间管理

## 使用方式

1. 复制任意提示词到 ChatGPT、Claude、DeepSeek、Kimi 等 AI 工具
2. 替换方括号 `[ ]` 中的内容为你的实际信息
3. 根据效果微调语气、长度等要求
4. 组合使用多个提示词完成更复杂的任务
